# Development history

Intermediate versions of the algorithms written during development on the six
development benchmarks (`_<key>_v<N>.py`, `_<key>_dev.py`). They are not used by
the benchmark: the frozen algorithms are the files in `gopt/algorithms/`, whose
checksums are listed in `docs/freeze_manifest.json`. Kept for transparency only;
their relative imports refer to the package layout of `gopt/algorithms/`.
